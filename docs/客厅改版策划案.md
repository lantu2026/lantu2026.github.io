## 1 边界：这次动什么、不动什么

### 1.1 要改的

- 首页的命名、标语、署名结构
- 视觉精细度：图标、字体、对齐、圆角、间距
- 「关于本站」的文案

### 1.2 不改的

| 不动的东西 | 原因 |
|---|---|
| 17 件作品的目录路径（`works/xxx`、`learn/xxx`） | 这些网址已经发给过学生、贴在过课件和二维码里。一改，所有外链和已打印的二维码全部失效 |
| 子页面左下角的「← 作品集」回流入口 | 刚做完、已验证、逐字节无损，没有理由再碰 |
| 免登录、单文件、可断网运行 | 这是所有作品的价值前提，不是可选项 |
| 深浅色切换 | 已有且可用 |

**这条边界比任何视觉改造都重要。** 名字可以改、脸可以换，路不能挪。

## 2 命名与署名

### 2.1 三层署名结构

前台是 IP，后台是实名。这是唯一稳妥的做法：纯 IP 会切断评优、课题、讲座的信用链；纯实名又回到简历感。

| 位置 | 写什么 |
|---|---|
| 浏览器标签（title 标签） | 蓝兔 · 数字教学作品集 \| fujinglei |
| 顶栏（宽屏，`.bf`） | `蓝兔 · 数字教学作品集` |
| 顶栏（窄屏，`.bs`） | `蓝兔的作品集` |
| 徽标 | 蓝色方块，内含「符」字或抽象符号（见第 5 节） |
| 页脚 | `符京雷（蓝兔）· 常州市新北区汤庄桥小学` / `信息科技教师` |
| 「关于本站」 | 正文中出现一次中文全名「符京雷」 |

### 2.2 关于 `fujinglei`

**它的作用**：让搜索引擎和“输拼音找老师”的场景仍能落到本页。

**它的局限**：中文「符京雷」三个字本身，搜索引擎无法从 `fujinglei` 反推。所以第 2.1 节最后一条——在「关于本站」正文里出现一次中文全名——不是可省略的细节，它是让这条路走通的唯一办法。搜索引擎索引页面正文里的中文。

**不建议的做法**：加 meta keywords 标签。主流搜索引擎早已忽略它，加了只是心理安慰。

### 2.3 移除「教师发展处」

首页三处出现这个职务（导语、页脚、`meta description`）。它是行政机关色彩，会让访客误判为部门官方站点，也让“个人教学资源库”的定位变模糊。

处理：从首页全部移除，只在「关于本站」的身份说明里保留。

## 3 标语的三种长度

一句话要在三个场景用，长度完全不同。只写一句，另外两处必然临时凑。

### 3.1 首屏主标题（35px，一行）

> 把工作与学习，做成能用的网页

- 15 字，宽屏一行放得下（左栏约 774px，35px 中文约 525px）
- 「能用的网页」继续用绿色高亮，与原设计一致
- 关于句式：这是“把 A 做成 B”的省略式，靠语感成立。若补全成“把工作与学习要用的东西做成能用的网页”，反而笨重。**保持省略，不要补全。**

为什么不用“一页页”：原句的“一页页”暗示很多页文档，但集合里已有 39 课时课程站、有数据大屏，这些不是“一页”。删掉后句子更短更有力。

### 3.2 分享与搜索摘要（`meta description`）

> 蓝兔的数字教学作品集：把工作与学习，做成能用的网页。17 件真上过课的东西，免登录、断网也能开。

约 55 字，在搜索引擎摘要的显示长度内。

### 3.3 口头一句话（讲座、跟同事介绍）

> 我做的东西，都是打开就能用的网页。

不讲方法论，讲结果。前两句是写给页面看的，这句是讲给人听的。

## 4 视觉系统

按收益排序，前两项成本极低、提升最明显。

### 4.1 图标：emoji 换成单色 SVG

**这是目前“不够精美”的最大来源。** 17 张卡片全靠 emoji，而 emoji 由操作系统渲染——Windows 用 Segoe UI Emoji，苹果用 Apple Color Emoji，安卓又是另一套。同一个页面在三台设备上是三种长相，观感无法控制。

换法：内联单色 SVG，描边 1.5px，尺寸 22×22，颜色跟随主色变量。

| 作品 | 图标语义 |
|---|---|
| 数智赋能 | 积木 / 拼合方块 |
| WorkBuddy 教师数字化实战 | 机器人头 |
| 信息老师应用全指南 | 打开的书 |
| 勤美汤小 wiki | 多人 / 对话气泡 |
| 光合作用 | 叶片 |
| 种植体验 | 水滴 + 嫩芽 |
| 保温水壶 | 壶身 + 温度线 |
| 组装台灯 | 灯泡 |
| 算法流程图 | 三个节点的连线 |
| AI 素养测评（护眼） | 眼睛 |
| AI 素养测评（大屏） | 仪表盘 |
| 信息科技乐园 | 圆环齿轮 |
| 课堂任务大闯关 | 靶心 |
| 课堂知识竞赛 | 抢答牌 |
| 打字乐园 | 键盘 |
| 枚举算法 | 清单 + 放大镜 |
| 电脑第一课 | 显示器 |

留一处例外：如果某件作品本身就是卡通风格、自带角色形象，可保留该形象作为图标，与整体单色图标并存不算违和。

### 4.2 字体

| 用途 | 现在 | 建议 |
|---|---|---|
| 中文标题 | 系统黑体 760 | 降到 600；标题改宋体（思源宋体或方正小标宋），宋黑对比一来就有文人感，也贴“勤美”二字 |
| 正文 | 系统黑体 | 保持 |
| 数字 | 系统默认 | 加等宽数字（tabular-nums） |

字号不变。**只调字重和字族，不动字号**——字号一动，整页的间距全要重算。

### 4.3 数字与对齐

统计条、卡片编号、日期列，凡是有数字纵向排列的地方，都加等宽数字设置（tabular-nums）。

现在数字宽度不等，“17”和“4”的右边缘参差，肉眼能看出。

### 4.4 圆角与阴影：收敛成三级

现状是零散数值，每张卡可能略有不同。收敛后整页会“静”下来。

| 级别 | 圆角 | 用于 |
|---|---|---|
| 小 | 10px | 标签、按钮、胶囊 |
| 中 | 14px | 作品卡片 |
| 大 | 18px | 区块容器、通栏特色卡 |

阴影同样收成三档：静止、悬停、浮层。悬停只做「位移 1px + 阴影加深」，**不要做缩放**——缩放会让文字边缘发糊。

### 4.5 间距：8px 栅格

所有 `padding` / `margin` / `gap` 收敛到 8 的倍数（8 / 16 / 24 / 32 / 48）。目标是消除所有 13px、22px 这类随手写的数值。

## 5 IP 符号（待定）

「蓝兔」要成立，需要一个能一眼记住的图形。三选一：

| 方案 | 描述 | 优点 | 风险 |
|---|---|---|---|
| **A 印章** | 方形、朱红、阴文，刻「蓝兔」或「符」 | 极有中国味，贴“勤美”；教师作品集用印章辨识度很高 | 与现有绿色主色冲突，需调整配色或只用在小面积 |
| **B 蓝方块** | 保留现在的方块，改为蓝色系，内含抽象符号 | 改动最小，与现有设计同源，深浅色都好处理 | 辨识度一般 |
| **C 不做符号** | 只用文字 | 零风险 | "IP“停留在名字层面，较难形成记忆 |

**必须避开的**：不画具体兔形。”蓝兔"作为个人昵称完全没问题，但视觉符号若照着《虹猫蓝兔七侠传》的角色做，会带来不必要的联想与风险。抽象色块、汉字、几何图形都安全。

建议先做 **B**（成本最低、与现设计同源），观察一段时间再决定是否升级到 **A**。

## 6 页面结构

现在的五段式是合理的，不推翻。只把每段负责回答的问题对齐。

| 段落 | 回答的问题 | 现状 | 需调整 |
|---|---|---|---|
| 门厅（顶栏 + 首屏） | 这是哪儿、谁做的 | 主张占据了门牌位置 | 改标语、改署名 |
| 主墙（快捷区 + 搜索） | 最常用的在哪 | 已到位，按打开次数自动排序 | 不改 |
| 两间房（作品 / 学件） | 都有什么 | 17 张卡平铺 | 换图标 |
| 说明牌（关于本站） | 怎么用、什么时候更新 | 已到位 | 补中文实名、去掉职务 |
| 落款（页脚） | 出处、许可 | 已到位 | 改署名 |

### 6.1 一处措辞问题

「专业成果 / 学生学件」对同行清楚，对家长和第一次来的人不清楚。「学件」是行话。

处理：栏目名保留，在两个标题下各加一行小字——`专业成果 · 给老师看的`／`学生学件 · 给学生用的`。改小字比改栏目名安全，已发出去的链接文字不用跟着改。

### 6.2 往后一步的隐患

现在 17 件，平铺加搜索够用。**超过 25 件，访客会开始“翻不动”**，需要加标签筛选（年级 / 学科 / 类型）。

这件事现在不做，但卡片上应保留可扩展的分类标记，届时不用重写卡片结构。

## 7 执行顺序与验收

### 7.1 阶段划分

| 阶段 | 内容 | 风险 | 可回退 |
|---|---|---|---|
| P0 | 命名、标语、署名、`meta`、移除职务、补中文实名 | 无 | 是 |
| P1 | 数字对齐、字重、圆角阴影收敛、8px 栅格 | 低 | 是 |
| P2 | 17 个单色 SVG 图标 | 中，逐个替换 | 是 |
| P3 | IP 符号落地 | 低，取决于方案 | 是 |
| — | 换肤 | 不做 | — |

P0 与 P1 可以一次做完。P2 建议分批，每批 4-5 个，替换后截图对照。

### 7.2 验收标准

上线前逐条打勾：

- [ ] 页面标题与搜索摘要已更新，摘要长度未超
- [ ] 顶栏宽屏 / 窄屏两套文字都正确
- [ ] 首页已无「教师发展处」
- [ ] 「关于本站」出现一次中文全名「符京雷」
- [ ] 全站无 emoji 图标（或仅保留明确例外）
- [ ] 数字纵向对齐，右边缘无参差
- [ ] 圆角只剩三档、间距只剩 8 的倍数
- [ ] 深浅色模式下无不可读文字
- [ ] 17 个链接全部 200
- [ ] 断网打开首页与任一学件仍可用
- [ ] 子页面「← 作品集」未被破坏

## 8 风险与待定

| 项 | 说明 | 处理 |
|---|---|---|
| `fujinglei` 中文检索落空 | 拼音无法反推汉字 | 「关于本站」保留中文全名 |
| 若将来用学校名义 | 以校名对外发布通常需对学校宣传口径 | 目前不用校名做站名，规避 |
| 子页面无法跟随换肤 | 17 个页面颜色各自硬编码 | 已排除换肤，不构成问题 |
| 17 → 30 件 | 平铺会失效 | 卡片保留分类标记，届时加筛选 |
| 印章方案与绿色主色冲突 | 朱红 + 绿不协调 | 若选方案 A，需同步调主色，成本上升 |

记下「为什么」，以防半年后忘了当初的取舍。
