PART 03 · 怎样制作 · 原创篇

✍️ 方法一：提示词 + AIGC 原创制作

🧩 万能提示词公式

身份定位 + 教学场景 + 适用对象 + 功能要求 + 页面风格 + 输出格式

📋 中小学教师通用提示词模板（可直接复制） 你是专业的前端工程师 + 中小学课件设计师，擅长制作简洁易用的课堂互动式网页学件。 请为【学科】学科【年级】年级【课题】制作一个【功能类型】网页学件，适配学生使用。 要求实现【核心互动】功能，页面简洁大方、配色柔和、字大清晰，适合课堂投影展示。 纯HTML+CSS+JS代码，无需后端，直接输出完整代码，我要直接保存使用。（务必提供详实内容）

校园扩音系统: ["扩音音箱", "麦克风", "广播控制终端"],

校园安防系统: ["摄像头", "监控平台", "红外报警器"],

人员管理系统: ["学籍管理平台", "请假考勤平台", "师生信息数据库"],

智慧教室系统: ["智能黑板", "课堂录播设备", "智能照明、空调控制"],

校园一卡系统: ["一卡通终端(门禁/食堂)", "充值管理平台", "消费记录数据库"],

图书管理系统: ["自助借阅机", "图书检索平台", "图书库存数据库"]

推荐工具：豆包 / Kimi / 通义千问 / DeepSeek  |  提示词网站：AiShort · Prompt123.cn

⭐ 实操任务一

🛠️ 【任务一】通过提示词制作网页学件

1

打开 AI 工具

2

复制提示词模板，快速替换

3

5

双击打开，查看效果

完成！

PART 03 · 怎样制作 · 修改篇

🔧 方法三：让别人的学件变成自己的

招式一：记事本简单修改 零门槛

右键 HTML → 记事本 → Ctrl+F 搜索关键词 → 替换内容 → 保存。改题库、改颜色(color/background)、改字号(font-size)统统可以！

招式二：DeepSeek 复刻在线版 进阶

复制飞象网在线链接 → 发给 DeepSeek："请访问这个链接，复刻离线版本，数据改为可编辑 JSON 格式" → 保存本地修改，完全自主可控

招式三：扣子 / Workbuddy 打通数据流 高阶

上传 HTML 学件 → 配置数据收集 → 学生提交答案 → 实时统计 → 大屏展示；教师看全班答题情况，学生获即时反馈

PART 04 · 怎样应用 · 本地篇

💻 4.1 本地应用：单机版、线下

🎯 适用场景

日常教学、公开课、调研课——无需网络，即开即用

将 HTML 文件拷贝到教室电脑 → 双击打开 → 配合投影仪/电子白板使用

✅ 核心优势

⚡ 零网络依赖，断网也能用

🚀 启动速度快，即点即用

🎨 可结合 PPT 原有演示方式

📦 单文件分发，简单轻便

本地版 = 最简单的起点，
今天学完就能立刻用！
